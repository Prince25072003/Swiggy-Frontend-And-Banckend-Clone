## 💻 Frontend

- React & ReactDOM
- Parcel (Bundler)
- JSX / Babel
- Data Fetching
- React Hooks (`useState`, `useEffect`, `useMemo`, `useRef`, `useContext`)
- Custom Hooks
- React Router
- Redux (`useSelector` + API handling)
- Tailwind CSS
- React best practices (why not to use index as `key`)

## ⚙️ Backend

- REST API
- API-level & Schema-level validation
- JWT Authentication
- Authentication Middleware
- Express.js
- MongoDB
- Redis
- Rate Limiting

Backend Commands:
# Install dependencies
npm install

# Install Nodemon
npm install nodemon

# Start the backend
node index.js

# OR start with Nodemon
npx nodemon index.js

Frontend Commands:
# Install dependencies
npm install

# Start the frontend with Parcel
npx parcel index.html
